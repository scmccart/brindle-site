# brindle-site

The website for [Brindle](https://github.com/scmccart/brindle), a GPU-accelerated terminal emulator for Linux and Windows.

Astro, React islands, Tailwind 4 and shadcn/ui, published to GitHub Pages at https://scmccart.github.io/brindle-site/.

```sh
npm ci
npm run dev
npm run build
```

`src/styles/brindle-tokens.css` is generated by `brindle --export-ui-tokens` and refreshed from each Brindle release by the `refresh-tokens` workflow. Don't edit it by hand. See `CLAUDE.md` for the site's rules.
